# 💻 Introduction to Operating Systems (Module 1)

## 📌 What is an Operating System?
An **operating system (OS)** is software that manages hardware and allows users and applications to interact with a computer.

---

## 🖥️ Common Operating Systems

- **Windows**
  - Released in 1985  
  - Widely used in personal and enterprise environments  
  - Closed-source  

- **macOS**
  - Released in 1984  
  - Used on Apple devices  
  - Partially open-source  

- **Linux**
  - Released in 1991  
  - Fully open-source  
  - Highly important in cybersecurity  

- **ChromeOS**
  - Released in 2011  
  - Based on Chromium OS  
  - Common in education  

- **iOS**
  - Released in 2007  
  - Mobile operating system for Apple devices  

- **Android**
  - Released in 2008  
  - Open-source mobile operating system  

---

## ⚠️ Legacy Operating Systems

A **legacy OS** is outdated but still in use.

### Why they are used:
- Compatibility with older software  
- Specialized systems or equipment  

### Risks:
- No longer receive updates  
- Vulnerable to modern security threats  

---

## 📱 Applications
An **application** is software designed to perform a specific task for the user.

---

## ⚙️ System Startup Components

### BIOS (Basic Input/Output System)
- Found in older systems  
- Initializes hardware during startup  
- Hands control to the bootloader  

---

### UEFI (Unified Extensible Firmware Interface)
- Modern replacement for BIOS  
- Provides improved security and performance  
- Also launches the bootloader  

---

### Bootloader
- Program that starts the operating system  

---

## 🔄 How a Computer Completes Tasks

1. **User** → initiates an action  
2. **Application** → receives the request  
3. **Operating System** → processes and directs the request  
4. **Hardware** → performs the task and returns output  

---

## 🧠 Memory (RAM)

- **RAM (Random Access Memory)** stores temporary data  
- More RAM allows better multitasking and virtualization  

---

## 🧪 Virtualization

### What is Virtualization?
Using software to create virtual versions of physical systems.

---

### Virtual Machines (VMs)
- Simulated computers running inside a host system  
- Use virtual hardware (CPU, storage, etc.)

---

### Benefits of Virtual Machines

- **Security** → isolated environments (sandboxing)  
- **Efficiency** → run multiple systems on one machine  

---

## 🛠️ Hypervisors

A **hypervisor** manages virtual machines and connects them to physical hardware.

### Example:
- **KVM (Kernel-based Virtual Machine)**
  - Open-source  
  - Built into Linux  
  - Widely used in virtualization  

---

## 🌐 Other Forms of Virtualization

- Virtual servers (multiple servers on one machine)  
- Virtual networks (optimize physical network resources)  

---

## 🧑‍💻 User Interfaces

A **user interface (UI)** allows users to interact with the operating system.

---

### 🖱️ Graphical User Interface (GUI)

- Uses icons, windows, and menus  
- Easy to use but less flexible  

**Examples:**
- Desktop  
- Taskbar  
- Start menu  

---

### ⌨️ Command-Line Interface (CLI)

- Text-based interface using commands  
- More powerful and flexible than GUI  

---

### Advantages of CLI

- Faster for experienced users  
- Can perform multiple tasks at once  
- Stores command history for tracking actions  

---

## 🧠 Key Takeaways

- Operating systems manage communication between users, software, and hardware  
- Linux is especially important in cybersecurity due to its flexibility and control  
- Virtualization allows secure testing environments  
- CLI is a critical skill for cybersecurity professionals
